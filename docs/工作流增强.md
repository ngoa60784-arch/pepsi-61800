# 结构化任务、证据与评测

当前工作流在 Planner / Solver / Observer / Verifier 之上增加了以下持久能力：

- `campaign.db` 保存依赖任务 DAG、任务预算与状态、证据制品、运行追踪和 FTS5 长期记忆。
- Planner 使用 `planner_create_task` / `planner_update_task` 拆分工作，只能将依赖已完成的 ready 任务派发给 Solver。
- Solver 使用 `record_artifact` 登记命令输出、HTTP 抓包、截图、PoC、loot 指针或报告，再以证据 id 更新任务或提交 finding。
- 外部工具结果会被标成不可信目标数据；重复工具调用与无新增结果会触发路线切换提醒。
- `bun run eval:roles` 检查角色/模型绑定；加 `--live` 执行真实模型工具调用资格测试，可用 `--prompt=NAME` 限定角色。
- `bun run eval:regression --manifest=benchmarks/pentest-regression.example.json` 启动授权测试靶场、执行非交互 runner，并对完成任务、证据数及错误 span 做回归断言。

Web API：

- `GET/POST /api/challenges/:id/campaign-tasks`
- `PATCH /api/challenges/:id/campaign-tasks/:taskId`
- `GET /api/challenges/:id/artifacts?taskId=...`
- `GET /api/challenges/:id/long-term-memory?q=...`

旧的 JSON 记忆无需手工迁移：第一次长期记忆查询时会自动回填到 FTS5 索引。
